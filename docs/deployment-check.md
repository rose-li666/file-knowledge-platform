# 独立源码与冷构建核查

新回归入口从指定源码目录的Dockerfile/Compose构建，不挂载宿主机前后端代码或模型。`--source-dir`供从Git archive导出的提交源码使用，`--source-sha`记录输入版本，`--no-cache`要求每个RUN重做依赖安装和模型下载。测试时才只读挂载ZIP，正常启动不需要它；默认空库。

历史阶段入口已转入最终独立回归。外部HTTP验证入口需要隔离测试marker，防止直接指向演示服务；marker仅作用于脚本，不改变应用功能。新的P0和检索质量runner分别使用自己的空卷，不能混用数据。模型运行离线，单worker/索引串行/数据卷方式保持不变。

冷构建和导出源码部署实际结果将在运行后补充。此处不预填通过。
