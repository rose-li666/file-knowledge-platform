# 技术限制与验证边界

本说明列出现有实现的技术范围及测试证据边界。部署与操作见[README](../README.md)，题目要求到页面/API和证据的对应关系见[acceptance.md](acceptance.md)。

## 技术限制

- PDF支持名称搜索、原文件预览和下载，不提取正文，不支持扫描件OCR。
- 语义检索仍可能返回高分但无关的流程资料，来源片段也可能偏泛化。默认相对窗口可能隐藏低分相关文件，可展开更多；相似度不是相关性概率，不保证未知问法的精度或召回。
- 精确向量遍历、单索引消费者及单推理锁适用于小资料集，未压测大型库。
- 重复上传保存为独立文件ID，无文件去重或版本管理。文件只有一个主分类，批量整理最多100份；刷新不保留勾选，并发移动以最后提交为准。
- 无目录树、问答、登录/复杂权限或多服务拆分。架构与组件来源见[delivery.md](delivery.md)。

## 已有验证证据

独立Git源码无缓存部署、空卷与HTTP/向量/分类/归档/故障恢复/重启重建回归见[完整回归报告](final-candidate-review.md)。39题检索对照、新源码空卷HTTP、分类过滤、归档恢复及下载SHA核对见[retrieval-round.md](retrieval-round.md)。这些是已执行的历史证据，不代表在每台新机器自动通过；新环境应按README的测试入口生成自己的结果。

## 未专项验证范围

用户已确认核心功能交付复核通过。用户手动普通Chrome批量分类及此前汇总确认见[user-validation.md](user-validation.md)；自动化和Agent浏览器证据按来源分别记录。PDF阅读器显示、普通Chrome正文ready/向量failed、低高度/390px键盘操作等专项人工明细未提供，不能据此补造逐动作、尺寸或截图。未专项压测大库，也未单独验证Windows Docker Desktop以外的宿主系统。
