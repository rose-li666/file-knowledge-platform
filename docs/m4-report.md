## 改动范围与验证清单

- TXT/Markdown 严格解码并持久化正文，PDF 仅名称搜索。原文件提交后才提取；正文失败不回滚上传或改写原文件。
- 关键词字面子串匹配，支持中文及完整编号，保留连字符与下划线；分类和归档过滤复用列表规则。
- GET /api/v1/search/keyword 返回元数据、命中字段、上下文和高亮偏移；空结果 HTTP 200，参数及数据库异常有反馈。
- 页面搜索/清除、分类组合筛选、搜索条件 URL 保留、片段高亮、未就绪正文提示及详情重试。
- 验证中文关键词、完整编号、PDF 名称、空结果、分页、移动 → 搜索 → 归档 → 搜索 → 恢复 → 搜索，以及提取失败仍可下载。

schema 从 1 升级到 2，增加 document_texts 与 text_error/text_encoding。每文件一条正文，原文 content 和规范化 search_content 分开保存。SQLite 参数化 instr 做字面包含；少量验收资料优先确保中文/编号可查，不声称大库检索性能。一个服务、一个 Web worker 和原 /data 挂载不变；正文提取通过进程锁串行。

API 和取舍详见 platform/docs/m4-api.md。语义检索未实现；vectorStatus 仍 not_started。持久化任务恢复、向量片段去重和故障注入仍留到 M5。
