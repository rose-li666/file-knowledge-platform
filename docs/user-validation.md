# 用户手动验证记录

本文件只记录用户在会话中明确确认的事实。它不是自动化测试日志，也不根据服务器记录推断用户做过哪些动作。早期消息没有逐项时间戳，不补造时间、截图或协作记录。

| 会话阶段 | 用户原始确认/报告 | 可记录结果 | 不能推断的内容 |
| --- | --- | --- | --- |
| M1 | “Docker 构建、启动和容器验证已通过，页面可访问，数据库按钮操作及刷新结果也已确认。” | 用户手动：页面可访问、数据库按钮/刷新通过；用户报告Docker验证通过（另有自动化日志） | 浏览器品牌、窄屏尺寸未在该消息给出 |
| M2 | “M2 容器校验已通过，浏览器上传、详情和下载也已确认。” | 用户手动：上传、详情、下载通过 | 不把此消息当作下载SHA自动化计算证据 |
| M3 | “M3 认可，未测项继续追踪。” | 用户认可阶段交付；未测项继续保留 | 不补写用户逐次创建/改名/移动/归档的动作 |
| M4 | “M4 容器日志已通过，请先补浏览器验证” | 用户报告容器日志通过；浏览器由Agent随后验证 | 不标为用户已经完成M4浏览器测试 |
| 普通Chrome核对 | “我会核对并回复” | 待实际结果 | 不是“通过” |
| 本轮检索质量反馈 | “借来的设备坏了应该怎么办？”正确命中设备文档，同时返回无关发布资料 | 用户手动：正确召回设备资料，但存在误返回；Agent只读HTTP另行复现（0.640802设备、0.483835发布） | 不将该个例推断为所有语义查询通过 |
