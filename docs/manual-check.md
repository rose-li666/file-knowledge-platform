# 人工验收步骤与确认范围

普通Chrome的添加文件入口、多选移动、数量更新、刷新保留、关键词与语义搜索分类过滤已由用户确认通过，原话见[user-validation.md](user-validation.md)。用户后续汇总回复“我已验证完成”，记为人工汇总确认，未附逐项尺寸/截图。下列步骤保留为验收参考，不要求重复已确认操作；Agent独立源码完整回归见final-candidate-review.md。

普通Chrome打开 http://localhost:8000 并硬刷新，然后核对：

1. **创建/改名**：管理分类创建一个分类；选中后再打开，确认原名自动填入。改名→筛选→刷新，名称、文件归属和选中状态仍保留。
2. **低高度与约390px**：降低窗口高度，在分类列表/文件选择弹窗用鼠标滚动；输入、保存、取消仍可见。Tab/Enter完成改名，Escape取消；窄屏完成多选与提交、上传、搜索及详情开关，无横向滚动。
3. **归档恢复**：对一个已索引TXT/MD，记录能命中的关键词和自然语言问题；归档后默认列表及两种搜索都排除，归档区仍可找到并下载；恢复后列表、两种搜索重新出现且可下载。
4. **新版主要入口/反馈**：补核普通Chrome上传TXT/MD/PDF、状态更新、详情/下载；空查询结果和“展开更多结果”可操作。检查超限提示；索引失败/部分移动失败与重试提示已有隔离自动化和内置浏览器证据，用户未提供这些专项的单独动作明细，后续需要复现时使用隔离测试服务。
5. **可选PDF预览**：详情预览是否显示PDF页面；不能渲染时下载可用。这是可选扩展，PDF正文/OCR不在本轮范围。

回复实际通过的编号、浏览器/宽高及具体失败点即可。早期上传/详情/下载人工确认仍保留，此处补的是新版普通Chrome兼容性。自动化下载SHA校验已通过，不需要重复声称人工计算过哈希。
