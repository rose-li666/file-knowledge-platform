# 简短人工验收步骤

普通Chrome打开 http://localhost:8000 ，先硬刷新加载最新页面。以下为待执行步骤，不是通过记录；约390px再核对相同主要操作、详情关闭和无横向滚动。可用自己准备的虚构资料，不删除演示资料。

1. 上传一份TXT和一份MD：确认进度/保存成功，点击“查看文件”，等待“可语义检索”；再上传PDF，核对详情元数据及下载。
2. 分类侧栏/窄屏“管理分类”：新建“人工验收”，改名“人工验收-设备”；把设备TXT移入，选择该分类后刷新，文件/分类数及选中状态保留。
3. 关键词查正文“设备管理员”（有命中片段），自然语言查“借来的设备坏了应该怎么办？”（设备来源片段）；另选不含该文件的分类，两种搜索都不能返回它。清除搜索/筛选可回到全部文件。
4. 归档该TXT：默认文件库、关键词和语义均排除；归档区可找回/下载。恢复后默认列表和两种搜索重新出现，再下载。
5. 搜索“土星的光环由什么构成？”检查空结果；设备问题的“展开更多结果”与收起入口可操作，同名文件用ID/分类/上传时间区分。
6. PDF详情点击在线预览，检查是否显示页面；浏览器不能渲染时确认下载可用。约390px检查上传/分类/搜索/归档/详情按钮可达，无横向滚动。

按步骤回复通过编号、浏览器与屏宽、具体失败点即可。不要把内置浏览器结果记成普通Chrome通过。下载文件可在PowerShell用 `Get-FileHash -Algorithm SHA256 -LiteralPath <文件路径>` 对比详情SHA及原文件；自动化SHA验证已有独立证据。
