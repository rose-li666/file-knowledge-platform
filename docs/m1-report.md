## 正式文件落盘但数据库未提交

写入契约：临时文件 fsync → 持久化上传意图 → 原子改名并同步目录 → 提交文件元数据事务（后续索引任务在同事务提交）→ 返回成功 → 清理意图。启动独占对账时，没有数据库引用的正式文件及意图进入隔离区，不自动生成可见文档或删除；数据库有记录但字节缺失/不一致时保留记录并明确报告存储异常。M1 仅文档化，见 docs/crash-consistency.md。
